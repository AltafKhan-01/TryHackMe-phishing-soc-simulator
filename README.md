# TryHackMe Phishing SOC Simulator

## Overview

This repository documents phishing alert investigations completed through the TryHackMe SOC Simulator.

The purpose of this project is to demonstrate practical SOC analyst skills including phishing email analysis, alert triage, IOC identification, investigation, verdict determination, and recommended response actions.

## Skills Demonstrated

- Phishing Email Analysis
- SOC Alert Triage
- Splunk log analysis
- IOC Identification
- URL and Domain Analysis
- Email Header Analysis
- Threat Intelligence
- Incident Investigation
- False Positive / True Positive Classification
- Recommended Response Actions
